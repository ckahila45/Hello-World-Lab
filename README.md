# Hello World Lab

This repository contains a simple HTML5 webpage created for a web development lab.



## The project demonstrates:

- A valid HTML5 document
- Multiple HTML elements inside the `<body>`
- Semantic HTML elements
- Metadata inside the `<head>`
- HTML comments documenting the metadata
- A properly formatted image with alternative text
- Git version control
- GitHub repository hosting
- Netlify deployment
- No CSS
